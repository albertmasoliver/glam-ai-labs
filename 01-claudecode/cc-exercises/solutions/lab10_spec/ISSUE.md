# #39 — Add a checkout flow for orders

Implement the checkout flow for the marketplace app. Users should be able to review
their cart and complete payment. Include email confirmation.

Potential improvements while we are in here:

- Progress indicator (cart → review → payment → confirmation)
- **Order review step with an itemised breakdown before payment**
- Save cart for later
- Apply discount codes
- Email confirmation
- Analytics tracking
- Support multiple payment methods
- Mobile responsive design

*This is not a single implementation task. It is a container for ideas, and the
first job is to find the one slice inside it that is worth a pull request.*
