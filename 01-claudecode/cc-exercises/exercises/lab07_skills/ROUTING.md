# Routing: one skill, three descriptions

Claude does not guess which skill to reach for. It ranks the descriptions it
loaded at startup against the words you actually typed, and the best match runs.
The description is dispatch logic. Break it on purpose and the routing changes in
front of you.

Ask the same question every time, and never name the skill in it.

**The question I asked:** <the sentence you typed, verbatim>

**1. Invoked by name:** <fired / did not fire>

**2. Description replaced with `helps with code`:** <fired / did not fire>

**3. Description rewritten in the words someone would say out loud:**
<fired / did not fire>

**The rewritten description, in full:** <paste the whole value of description:,
exactly as it now stands in SKILL.md>

**What the generic one was missing:** <one or two sentences. Name the words in
your question that the rewrite matches and `helps with code` does not.>
