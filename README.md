# glam-ai-labs

A growing collection of hands-on AI labs — original, self-contained exercises with a
fill-in-the-blank workbook, an automated verifier, and printable study guides.

## Labs

- **[`00-introduction/`](00-introduction/) — LLMs with Hugging Face `transformers`.**
  Using pre-trained models with `pipeline()`, the three transformer shapes, tokenization
  (`input_ids` / `attention_mask`), datasets & `.map`, `TrainingArguments`, the `Trainer`, and
  inference from logits. 11 fill-in-the-blank exercises + solutions + a printable study guide.

More lab sets will be added as sibling folders (`01-…`, `02-…`).
