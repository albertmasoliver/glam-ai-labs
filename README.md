# glam-ai-labs

A growing collection of hands-on AI labs — original, self-contained exercises with a
fill-in-the-blank workbook, an automated verifier, and printable study guides.

## Labs

- **[`00-introduction/`](00-introduction/) — LLMs with Hugging Face `transformers`.**
  Using pre-trained models with `pipeline()`, the three transformer shapes, tokenization
  (`input_ids` / `attention_mask`), datasets & `.map`, `TrainingArguments`, the `Trainer`, and
  inference from logits. 11 fill-in-the-blank exercises + solutions + a printable study guide.

- **[`01-claudecode/`](01-claudecode/) — working with an agentic coding tool.**
  Writing a request that gets what you asked for, driving a session (context, modes,
  plans), letting tests force a design, project memory and scoped rules, permissions
  and the trust boundary, skills and hooks, subagents, landing in code you did not
  write, spec-to-pull-request, review and recovery, and where to stop. 12 labs with an
  artifact verifier + a printable study guide.

More lab sets will be added as sibling folders (`02-…`, `03-…`).
